# W3 任务清单 · 设定库 / 导入导出 / 备份

## 一、导入（已完成）

**入口**：书架顶部「导入稿件」、工作台顶栏「导入」。两者共用同一个对话框。

**流程**：选文件 → 选拆章规则 → 看预览 → 填书名/卷名 → 开始导入。

| 能力 | 说明 |
| --- | --- |
| 支持格式 | `.txt` / `.md` / `.markdown`，上限 50MB |
| 编码识别 | UTF-8（含 BOM）优先，失败退回 GBK —— 中文老稿常见 GBK |
| 拆章规则 | 「第X章/节/回」标题（含阿拉伯数字与中文数字）、Markdown 标题、空行分段、整篇一章 |
| 预览 | 章数、总字数、逐章标题与字数、识别告警（无标题、标题前有内容等） |
| 落库 | 一次事务：可选新建一本书（不建默认空章）或追加到当前项目的一卷 |
| 排版 | 每个非空行一段，字数与编辑器口径一致（纯文本重算） |

**实现**：

- `shared/split-chapters.ts`：纯函数拆章 + 规则标签，可单测
- `main/modules/import.ts`：解码、预览、`commitImport` 事务落库
- `shared/editor-doc.ts`：`textToDocJson` / `textToPlainText` 保证导入后的段落与编辑器一致
- IPC：`import:pick` / `import:preview` / `import:commit`
- UI：`features/import/import-dialog.tsx`

**已知取舍**：

1. Markdown 导入按行转段落，暂不解析粗体/引用等标记（首版保证"内容不丢"）。
2. 重名章节不自动去重；导入后可在卷章树里改名。
3. 暂不支持拖拽文件进窗口，只走文件选择框。

## 五、状态语义与「关联设定」补齐

### 章节状态：两态

| 状态 | 行为 |
| --- | --- |
| 可编辑（草稿 / 修改中） | 正常写作、自动保存 |
| 已完成 | 正文锁定，只读 |

- 右栏是「可编辑 / 已完成」两个按钮，卷章树里已完成的章显示 ✓
- 锁定是**主进程级**的：`saveChapter` 与 `restoreSnapshot` 都会拒绝，不只是把界面灰掉
- 解锁回到「可编辑」即可继续写
- 旧数据里的 `revising` 按可编辑处理，不需要迁移表结构

### 关联设定：两个补齐

1. **卡片里的章名可点击** → 直接跳到那一章（原来只是文本）
2. **提及提示**：正文写到已建的设定卡名称时，右栏出现「＋ 玄清」的一键关联提示
   - 默认关闭，右栏复选框开启（偏好存 `settings` 表）
   - 只检测 2 字以上的名称/别名，单字名不参与，避免「剑」这种误报
   - 已关联的不再提示

实现：`shared/mention.ts`（纯函数，可单测）、`modules/prefs.ts`（偏好读写）、`chapter:save`/`snapshot:restore` 的锁定校验。

### 设定卡：查看与编辑分离

点任何入口的设定卡（左栏列表、右栏关联标签、搜索结果）现在都先进入**「设定详情」只读视图**：

- 类型徽标、名称、别名、身份、描述、关系、出现在 N 章（章名可点击跳转）
- 底部只有「关闭 / 编辑 / 删除」，要改内容再点「编辑」
- 新建卡片直接进编辑态（还没内容可看）；保存后回到详情视图，而不是关掉弹窗

顺带修了下拉为空的 bug：右栏「关联设定」原先只用打开项目时的旧列表，新建的卡不出现。现在新建/删除后同步刷新、切章节时重新拉取，下拉会显示「（N 张可选）」；一张卡都没有时提示「去左栏新建」。挑选逻辑抽成 `shared/entity-picker.ts`（全部 − 已关联，中文名排序）。
